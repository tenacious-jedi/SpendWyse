# SpendWyse
A personal finance app to manage personal finances, bugeting with filters for checking category spending with catrgory tags, as well as alerting function when spending exceeds the alert spending rules set.
Agents are set as: 

Subscription Optimizer Agent - Finds hidden User subscripotion which are compounding over time( eg. annual renewals, free trials that converted, services billed under weird merchant names, duplicate streaming through bundles which needs investigation). It essentially investigates, eg. question- What is the the amount I'm leaking on subscriptions?

Savings Spend Agent - Agent that investigates why the spend went up in a particular category tag For eg. The spend on Uber Eats in the "Food/Dining" tag went up by $1000 dollars for last month, and prescribes a solution like say, At your historical dining frequency, dropping 4 of these would bring you back to baseline and save around $700/month.
