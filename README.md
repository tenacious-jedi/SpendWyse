# SpendWyse
A personal finance app to manage personal finances and bugeting with filters for checking category spending with category tags [eg. tuition, food, travel etc.] as well as an alerting functionality when spending exceeds the spending rules defined.
Agents are set as: 

Subscription Optimizer Agent - Finds hidden user subscripotions which are compounding over time (for eg. annual renewals, free trials that converted, services billed under weird merchant names, duplicate streaming through bundles which need investigation). It essentially investigates, problems like where is a user leaking money on his/her subscriptions?

Savings Spend Agent - Agent that investigates why the spend went up in a particular category tag that month. For eg. The spend on Uber Eats in the "Food" category tag went up by say $1000 dollars for last month. this agent investigates and prescribes a solution like say, At your historical dining frequency, dropping 4 of these Uber eats spends would bring you back to baseline and save around $700/month.
